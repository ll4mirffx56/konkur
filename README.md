# Amir's Academic OS

Static GitHub Pages-ready academic management web app for Konkur 1406.

## Deploy on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` (and this README if desired).
3. Repository Settings → Pages → Deploy from branch → `main` / root.
4. Open the generated Pages URL.

No Node.js, Python server, or build step is required.

## Data
Data is saved in browser `localStorage`. Use **Settings → Export JSON** for backup and **Import JSON** to restore/move data.

## Current modules
Dashboard, Today, Courses, Sessions/Learning Cycle, Tests, Analytics, Calendar, Goals/Roadmap, Academic Debt, Daily/Weekly Reviews, Notes, Mistake Book, Settings/Backup.
